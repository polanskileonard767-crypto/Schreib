# Schreib

Handschrift-Dataset für das Schriftboard-Projekt.

## Ziel

Dieses Repository sammelt die handschriftlichen Glyphen, aus denen später eine eigene Schrift erzeugt wird.

## Struktur

- `dataset/` – gespeicherte Glyphen und Metadaten
- `schema/` – Datenformat
- `tools/` – kleine Hilfsprogramme für Import/Export
